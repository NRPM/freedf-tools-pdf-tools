# FreeDF Tools

**A free, private, 100% client-side PDF tool suite.** Merge, split, compress, convert, organize, protect, sign, redact and more — 30 tools, all running entirely in your browser.

## ✨ Highlights

- **100% private** — every file is processed locally on your device. Nothing is ever uploaded to a server.
- **100% free** — no accounts, no paywalls, no premium tier, no limits.
- **30 tools** — merge, split, compress, PDF↔Word/PowerPoint/Excel, PDF↔JPG/PNG, organize, rotate, watermark, page numbers, crop, protect (real RC4-40 encryption), unlock, sign, redact, compare, OCR, repair, PDF/A, forms, and more.
- **Dark & light themes** — dark by default, with a smooth 250 ms animated switch.
- **No build step** — pure HTML, CSS and JavaScript. Host it anywhere, including GitHub Pages.

## 🚀 Run it

Just open `index.html` in any modern browser — or serve the folder:

```bash
python -m http.server 8123
# then open http://localhost:8123/
```

## ☁️ Deploy to GitHub Pages

1. Push this repository to GitHub.
2. In the repo settings, enable **Pages** → deploy from branch `main`, root folder.
3. Done — the app is live. No build step required.

## 🔒 Privacy

All document processing happens **on-device** using open-source libraries (pdf-lib, PDF.js, JSZip, Tesseract.js) loaded from a public CDN. Your files never leave your browser. The only thing stored locally is your theme preference.
